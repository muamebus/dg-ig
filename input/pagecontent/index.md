### Use Case

Eine Hausarztpraxis erfasst Arzneimittelallergien ihrer Patientinnen und Patienten. Die Notfallstation kann diese Informationen lesen und auswerten, um bekannte Allergien und mögliche Reaktionen bei der Behandlung zu berücksichtigen.

### Scope

Dieses IG beschreibt die Erfassung von Arzneimittelallergien auf Basis von CH Core AllergyIntolerance. Andere Allergiekategorien werden nicht abgedeckt.

### Artefakte

* [DG Arzneimittelallergie](StructureDefinition-dg-medication-allergy.html): Profil zur strukturierten Erfassung von Arzneimittelallergien.
* [Penicillinallergie Anna Muster](AllergyIntolerance-PenicillinAllergieAnna.html): Beispiel einer bestätigten Penicillinallergie mit dokumentierter Reaktion.

### Abhängigkeiten

Dieses IG baut auf [CH Core 6.0.0](https://fhir.ch/ig/ch-core/6.0.0/) auf.
